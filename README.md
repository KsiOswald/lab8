# Задание 1



## Задача 1



## Текст задачи



Чтение базы данных из бинарного файла. 



### Алгоритм решения

Программа проверяет существование файла, если файл не существует, то возвращается пустой список и сообщение о несуществовании файла.
Если файл существует, то файл открывается для чтения данных, первым элементом файла является количество фильмов
Затем по количеству фильмов считываются поля объекта - фильма (Название, год выхода, оценка, продолжительность в минутах, категория фильма)
После фильм добавляется к список фильмов

## Задание 3



### Текст задачи

Удаление элементов (по ключу). 


### Алгоритм решения


Ключевым полем в базе данных является название фильма.
Пользователю необходимо ввести с клавиатуры название фильма для удаления.
Далее находится указатель на фильм с названием, которое ввел пользователь.
Если такой фильм есть - фильм удаляется из списка фильмов, а данные перезаписываются в файл.
Если же такого фильм нет - выводится сообщение о том, что такого фильма нет базе даннных

## Задание 4



### Текст задачи

Добавление элементов. 

### Алгоритм решения

У пользователя запрашивается название, год выхода, оценка, продолжительность и категория фильма.
После ввода каждого данного происходит проверка на соответствие данных от пользователя типу данных (int и double).
Далее по этим данным создается фильм и добавляется в список фильмов
Затем данные записываются в бинарный файл.

## Задание 5



### Текст задачи

Реализация 4 LINQ запроса

### Алгоритм решения

Реализуется 4 запроса:
1. Нахождение всех фильмов, которые вышли после определённого года выхода.
У пользователя запрашивается год выхода, он проверяется на соответствие типу int
Далее производится LINQ запрос с нахождением всех фильмов, чьи годы выхода равна году, который ввел пользователь.
Затем все найденные фильмы выводятся на экран.

2. Нахождение всех фильмов, оценка которых выше определённой оценки.
У пользователя запрашивается год выхода, он проверяется на соответствие типу double
Далее производится LINQ запрос с нахождением всех фильмов, чьи оценки больше оценки искомой оценки.
Затем все найденные фильмы выводятся на экран.

3. Нахождение средней оценки фильмов.
С помощью LINQ запроса на основе списка фильмов находится средняя оценка фильмов
Если список пустой, возвращается 0.

4. Нахождение фильмов, относящихся к определённой категории.
У пользователя запрашивается номер категории, затем с помощью LINQ запроса находится количество фильмов, соответствующих искомой категории.
